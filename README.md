# say--tahmin-oyunu
Python ile geliştirilmiş terminal tabanlı basit sayı tahmin etme oyunu.

Bu proje Python öğrenme sürecimde terminal tabanlı ilk uygulamamdır.

## Özellikleri
- "random" komutu kullanarak rastgele sayı seçimi yapar.
- "int" dönüştürmesi kullanır.
- "input" komutu ile kullanıcıdan veri girişi alır ve kullanır.

## Nasıl Çalıştırılır
Terminalde "python main.py" komutunu yazıp çalıştırabilirsiniz
